Secure File Encryption Using RSA Asymmetric Cryptography

Muhammad Hassan
Dept. of Computer Science

Abstract—This paper describes a file security tool written in Python that uses RSA asymmetric encryption. The tool generates a public and private key pair, encrypts a file with the public key and restores it with the private key. It shows how public-key cryptography can protect data in a simple, working program.

Keywords—RSA, cryptography, file encryption, Python, information security

I. Introduction

Files stored or shared on a computer can be read by anyone who gets access to them. Encryption makes a file unreadable without the right key. Unlike symmetric encryption, RSA uses two keys, so the encryption key can be shared openly while the decryption key stays private.

II. Methodology

A. Key Generation

The tool first creates an RSA key pair. The public key is used for encryption and the private key is kept secret for decryption.

B. Encryption and Decryption

To encrypt, the file's contents are read and processed with the public key. To decrypt, the encrypted file is processed with the private key to get the original data back.

Fig. 1. Encryption and decryption workflow.

III. Results

The tool was tested on sample files. After decryption, the recovered file matched the original, which confirms that the key generation and the encryption and decryption steps work together correctly.

IV. Conclusion

This project applies the core ideas of RSA in a working program. Future work could add support for larger files and safer key storage.
